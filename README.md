# UFC Elo

This project is mostly in place, but it is still a work in progress.

## Current state

- The scraper is largely working and is the main part of the project that is mostly complete.
- There are still some minor inconsistencies in the scraped data, so it is not yet fully finalized.
- The project is usable as a foundation for continued development, but some cleanup and validation is still needed.

## Elo engine

- The Elo engine is also still being developed.
- The rating logic is being refined as the project evolves.
- It is not considered final yet, but the groundwork is in place and the system is actively being improved.

This repo is intended as an ongoing project rather than a finished product.
